# Ml_Journey
Here is my machine learning journey...
method overloading: manuplating builtin methods
method overriding: priority given to child class, given that both have same method name
duck typing: function which acts as a method, and takes a class as parameter. can call the method in that class inside function     
polymorphysm:ability of function to behave differently and perform different actions based on the context. "many forms"
